## Flowchart

The decision label `B{Works?}` also verifies that braces in MDX fences remain diagram text.

```mermaid title="Flowchart"
flowchart LR
	A[Start] --> B{Works?}
	B -->|Yes| C[Ship]
	B -->|No| D[Fix]
```
